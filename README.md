# Энергопрофили для Windows

[Скачать приложение для Windows](https://github.com/NotPengu1n/energy-profiles/releases/latest/download/EnergyProfiles-Windows.zip) · [Все релизы](https://github.com/NotPengu1n/energy-profiles/releases)

Готовые ZIP-файлы находятся в разделе **Releases → Assets**. Исходники Flutter доступны в этом репозитории и отдельным архивом в релизе.

Flutter-приложение: три фиксированных редактируемых профиля — Суперэкономия, Экономия, Плавность.

## Запуск
Распакуйте архив целиком и откройте energy_profiles.exe. Папка data и flutter_windows.dll должны находиться рядом с EXE. Flutter для запуска готовой сборки не нужен.

Выберите карточку профиля, настройте монитор, разрешение, частоту и яркость. Переключатель рядом с яркостью позволяет сохранить значение в профиле или оставить текущую яркость без изменения. Сохранить профиль записывает настройки; Применить также сохраняет профиль и переключает параметры Windows. Подтвердите новый режим за 15 секунд, иначе приложение восстановит прежние параметры.

## Энергосбережение Windows
Галочка управляет настоящей системной экономией энергии: устанавливает порог автоматического включения 100% в выбранном плане питания. Дополнительно включается классический план Экономия энергии, если он доступен, либо режим Максимальная энергоэффективность Windows 11. Состояние в верхней панели берётся из GUID_ENERGY_SAVER_STATUS, а не из старого индикатора батареи.

Без галочки восстанавливаются прежние план/режим питания и исходные пороги автоматического включения. Если батарея ниже исходного порога, сама Windows может оставить экономию включённой. При питании от сети поведение зависит от версии Windows. Приложение показывает фактический результат и сообщает, если Windows не подтвердила включение.

Яркость управляется через стандартные WmiMonitorBrightness/WmiSetBrightness. На встроенном экране ноутбука проверены чтение, изменение 80% → 70% и возврат 80%. Внешние мониторы, не предоставляющие этот интерфейс, отображаются без управления яркостью. Ползунок использует уровни, поддерживаемые драйвером.

## Настройки
%LOCALAPPDATA%\EnergyProfiles\profiles.json; резервная копия profiles.json.bak. Старые профили загружаются с отключённым изменением яркости. Для переноса настроек скопируйте этот файл. Неподключённый монитор не заменяется другим автоматически.

Возврат выполняет отдельный поток Windows-модуля, пока процесс работает, в том числе при обычном закрытии окна. Принудительное завершение процесса не позволяет выполнить возврат.

## Сборка исходников
Требуются Flutter 3.38.5 / Dart 3.10.4 или совместимые и Visual Studio с разработкой классических приложений C++ и Windows SDK 26100+.

flutter pub get
flutter analyze
flutter test
flutter build windows --release

Исходники интерфейса: lib/main.dart; модели и сохранение: lib/models.dart; Windows API: windows/runner/energy_backend.cpp, system_controls.cpp.

## Проверка
12 тестов: настройки, обратная совместимость, яркость, резервная копия, сохранение галочки, подтверждение/отмена/тайм-аут, минимальный размер окна. Дополнительно выполнены нативная проверка текущего режима через CDS_TEST и проверка перехода системной экономии энергии 0 → 1 от батареи с восстановлением исходных порогов.

## Данные батареи
Панель показывает текущий расход в ваттах, оставшуюся энергию в ватт-часах и приблизительное время работы. Данные обновляются каждые 5 секунд. Оценка рассчитывается по текущему расходу; при питании от сети или отсутствии данных показывается прочерк.

## Flutter и C++
Интерфейс и профили написаны на Dart. Канал app.energy/profiles связывает Dart и C++: WindowsApi вызывает invokeMethod, EnergyBackend принимает команды и обращается к Windows API. Сборка CMake объединяет нативную часть с Flutter в приложение Windows. Папка windows содержит необходимые исходники и конфигурацию; сборки и временные файлы исключены через .gitignore.
